## ✦ Sobre o projeto

A **Lunara Store** é um projeto pessoal de desenvolvimento web criado para praticar programação por meio da construção de uma loja virtual fictícia.

O site está sendo desenvolvido gradualmente, com atenção à estrutura do HTML, à estilização com CSS e ao entendimento de cada etapa antes de avançar para novas funcionalidades.

Além da programação, o projeto também permite explorar organização de código, composição visual, tipografia e criação de interfaces.

## 🌙 O que já foi desenvolvido

### ✦ Cabeçalho

- Logotipo e identidade visual inicial.
- Menu de navegação.
- Botões de pesquisa, conta e carrinho.
- Ícones construídos com SVG.
- Organização dos elementos utilizando Flexbox.
- Espaçamento com `gap`.
- Efeitos de `:hover` e transições com CSS.
- Aplicação da fonte Poppins.
- Cores e acabamento visual do cabeçalho.

### ✦ Seção de destaque

- Título e texto de apresentação.
- Botão "Comprar agora".
- Organização do texto e da área da imagem lado a lado.
- Card com fundo branco, borda e cantos arredondados.
- Espaçamento interno com `padding`.
- Sombra com `box-shadow`.
- Gradiente aplicado ao título.
- Efeito de hover e brilho no botão.

## 🎨 Identidade visual

A identidade da Lunara Store combina tons de azul-claro, azul-gelo, branco e azul-acinzentado, com detalhes escuros para criar uma estética delicada, moderna e celestial.

**Paleta de cores**

| Cor | Código |
|---|---|
| Azul-céu | `#87CEEB` |
| Azul suave | `#9CC7DA` |
| Azul-gelo | `#C6E6F5` |
| Azul acinzentado | `#598496` |
| Azul profundo | `#2F4149` |
| Grafite | `#1B2327` |
| Branco | `#FFFFFF` |
| Preto | `#000000` |

A fonte utilizada é **Poppins**, escolhida para manter uma aparência limpa e moderna.

## 🛠️ Tecnologias e recursos

- **HTML5:** estruturação do conteúdo.
- **CSS3:** estilos, layouts, cores e efeitos visuais.
- **SVG:** ícones da interface.
- **Google Fonts:** tipografia Poppins.
- **GitHub Pages:** publicação do projeto.

O JavaScript faz parte dos objetivos de aprendizado para as próximas etapas.
